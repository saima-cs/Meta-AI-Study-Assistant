# Meta AI Study Assistant 🤖📚

Your AI-powered study companion for learning, revision, and exam preparation.

Meta AI Study Assistant is a beginner-friendly AI web application built with Python, Streamlit, and the Groq API.

It helps students understand difficult concepts, generate study material, practice questions, create flashcards, build study plans, and learn programming.

---

## ✨ Features

- 📖 AI Tutor
- 📝 Notes Generator
- 🔎 Text Summarizer
- 🧠 Quiz Generator
- ✅ MCQ Generator
- 🗂️ Flashcard Generator
- 📅 Personalized Study Planner
- 💻 Coding Assistant
- 🎯 Simple, Detailed, and Exam-focused explanation styles
- 📚 Multiple subject options
- 💬 Modern AI chat interface
- 🔐 Secure Groq API key handling
